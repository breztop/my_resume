# Project image prompts

三张图片均通过内置 image generation 工具生成，统一为 3:2 横向、风格化 3D、无文字与无品牌标识的作品集概念图。

## P2P cooperative project

```text
Use case: stylized-concept
Asset type: landscape project cover for a game developer portfolio, 3:2 composition
Primary request: Create an original premium game concept image for a peer-to-peer cooperative puzzle platformer. Two small original elemental adventurers, one fire-themed and one water-themed, work together inside an ancient forest temple with mechanisms, pressure plates, glowing gates, and layered platforms. Convey cooperation and network synchronization through subtle paired light trails and mirrored interactions, without showing literal UI text.
Style/medium: polished stylized 3D game art, clean geometric forms, editorial portfolio quality, slightly isometric cinematic view, not photorealistic
Composition/framing: wide landscape, clear focal pair in the middle third, readable silhouettes, generous clean margins, suitable for cropping with object-fit cover
Lighting/mood: cool blue ambient light balanced by warm coral fire glow, thoughtful and adventurous
Color palette: pale periwinkle and cobalt blue with coral accents, dark charcoal details, consistent with a modern Swiss-editorial portfolio
Constraints: entirely original character designs; no logos; no typography; no interface labels; no watermark; no border; avoid resemblance to recognizable commercial game characters; avoid clutter
```

## Systemic tower-defense project

```text
Use case: stylized-concept
Asset type: landscape project cover for a game developer portfolio, 3:2 composition
Primary request: Create an original premium game concept image for a systemic tower-defense strategy game. Show an isometric battlefield with a winding enemy route, several clearly different modular defense towers, upgrade modules, resource nodes, and an approaching organized wave of small abstract enemies. The scene should visually communicate data-driven systems, range planning, and expandable strategy without any literal UI text.
Style/medium: polished stylized 3D game art, clean geometric forms, editorial portfolio quality, same visual family as a modern game-development case study
Composition/framing: wide landscape, strong diagonal path through the image, readable towers and enemy silhouettes, suitable for object-fit cover crop
Lighting/mood: bright strategic tabletop feel, crisp directional light, energetic but controlled
Color palette: vivid lime and chartreuse field tones, dark charcoal towers, warm off-white surfaces, restrained coral markers
Constraints: no logos; no typography; no interface labels; no watermark; no border; no recognizable commercial game assets; avoid clutter and photorealism
```

## Authoritative multiplayer project

```text
Use case: stylized-concept
Asset type: landscape project cover for a game developer portfolio, 3:2 composition
Primary request: Create an original premium game concept image for an authoritative-server card and board strategy game. Show a refined tabletop arena with several original abstract cards, chess-like tactical pieces, turn-state tokens, and subtle luminous network lines converging on a central secure server core represented as a geometric black monolith. Convey fair competitive rules, validation, deterministic turns, and reconnectable game state without literal UI text.
Style/medium: polished stylized 3D game art, clean geometric forms, editorial portfolio quality, same visual family as a modern game-development case study
Composition/framing: wide landscape, slightly elevated cinematic tabletop view, cards and pieces arranged in a clear duel, central secure core visible, suitable for object-fit cover crop
Lighting/mood: dramatic warm studio lighting, competitive and precise
Color palette: coral and vermilion field, deep charcoal, warm ivory cards, restrained cobalt and lime status accents
Constraints: all card faces use abstract symbols only; no readable words or numbers; no logos; no watermark; no border; no recognizable commercial cards or chess set; avoid clutter and photorealism
```
